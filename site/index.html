Comment les groupes votent-ils réellement ?

Ce site compare les groupes de l'Assemblée nationale à partir de tous leurs scrutins publics, pas d'une sélection de votes choisis à la main. Chaque score est recalculable : voici les votes qui rapprochent deux groupes, ceux qui les opposent, et à quel point le résultat dépend de la méthode.

Aucun jugement « gauche / droite » n'est injecté dans les données. Les positions affichées sortent des listes de vote officielles ; la carte est calculée après coup, uniquement pour la lecture.

Ce que ce site ne dit pas

Ce site ne recommande aucun vote et ne prétend pas dire « qui est proche de vous ».

Il montre une chose vérifiable : à quels scrutins publics deux groupes ont voté pareil, et selon quelles règles ce constat est établi. Un vote de groupe résume des députés qui peuvent voter différemment ; un scrutin isolé ne définit pas un programme. Les limites sont détaillées sur la page méthodologie.

Sources : Assemblée nationale (open data des scrutins, dossiers législatifs, acteurs et organes) ; Sénat (base Dosleg pour les thèmes). Données publiques sous licence ouverte. Chaque vote est relié à sa page officielle sur assemblee-nationale.fr.
